Milestone 12 - Project progress: production bundle inspection
Date: 2026-09-19
Build: npm run tauri build
Bundle: dist/ as produced by that build (Vite 7, production mode)

Milestones 6 to 11 checked that the development-only Git harness does not ship,
that the webview names no GitHub host, that the webview sends no write method,
and that no component sets inner HTML. All four are rechecked. The progress card
shows area names and task titles typed by whoever edited progress.json, and issue
titles written by other people, so the inner-HTML check matters here too.
